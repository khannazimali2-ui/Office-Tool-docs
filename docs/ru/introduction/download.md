::: details Установка Office Tool Plus через winget

Вы также можете установить Office Tool Plus с помощью winget:

```powershell
winget install Yerong.OfficeToolPlus
```

**Команду `winget install` необходимо запускать с правами администратора, иначе символическая ссылка не будет создана, и вы не сможете запускать Office Tool Plus следующими командами.**

После установки вы можете запускать Office Tool Plus следующими командами:

```powershell
OfficeToolPlus
```

```powershell
OfficeToolPlus.Console
```

Примечание:

- Пакет winget может обновляться не так быстро, как официальные релизы, поэтому в нём не всегда будет самая новая версия Office Tool Plus.
- Пакет winget не включает файлы .NET Runtime. При создании ISO-файла Office Tool Plus предложит скачать и установить .NET Runtime, если он не будет найден. Это может создать неудобства для пользователей, у которых .NET Runtime не установлен в системе.
- При загрузке установочных файлов Office вам всегда будет предложено выбрать место сохранения файлов.

:::

---

Различия между версиями:

- Includes Runtime: Включает .NET Runtime, что позволяет запускать Office Tool Plus без отдельной установки .NET Runtime.
- Normal: Включает только Office Tool Plus и его базовые компоненты.

> Мы рекомендуем скачивать версию, которая включает runtime.

## Распаковка

Распакуйте Office Tool Plus в стандартное место, например на рабочий стол. **Не запускайте Office Tool Plus без предварительной распаковки**.

## Запуск

Дважды щёлкните по `Office Tool Plus.exe`, чтобы запустить программу. Отключать антивирус не нужно — Office Tool Plus безопасен и надёжен.

Office Tool Plus защищён цифровой подписью. При запуске Windows распознает программу как исходящую от проверенного издателя. Если подпись была изменена или недействительна, прекратите использование программы и повторно скачайте Office Tool Plus с [официального сайта](#скачать).

## Удаление

Вы можете безопасно удалить Office Tool Plus. Поскольку это портативное приложение, стандартной процедуры удаления нет — просто удалите файлы программы.
