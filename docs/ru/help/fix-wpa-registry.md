# Исправление реестра WPA

::: danger Предупреждение

Не выполняйте эту операцию, если она явно не требуется.

:::

Когда в системе повреждён раздел реестра `HKEY_LOCAL_MACHINE\SYSTEM\WPA`, это может привести к сбоям активации Windows и Office, а также к высокой загрузке ЦП службой Software Protection. Эта операция удалит указанный раздел реестра, чтобы система могла создать его заново.

Этот раздел реестра защищён ОС, поэтому операцию необходимо выполнять в среде Windows PE.

## Шаги

- Скачайте [этот файл](https://github.com/asdcorp/rearm/archive/refs/heads/principalis.zip).
- После извлечения скопируйте файл `rearm.cmd` в корневой каталог системы, например `C:\rearm.cmd`.
- Выполните эту команду от имени администратора, чтобы войти в среду Windows RE: `shutdown /f /r /o /t 0`.
- В среде Windows RE выберите «Устранение неполадок» > «Дополнительные параметры» > «Командная строка».
- В командной строке введите следующую команду и нажмите Enter: `C:\rearm.cmd`.
- После завершения выполнения скрипта перезагрузите систему.

::: tip Подсказка

Если при выполнении команды `C:\rearm.cmd` появляется ошибка «команда не распознана», выполните команду `bcdedit | find "osdevice"`, чтобы проверить букву диска системного раздела, и замените `C:` в `C:\rearm.cmd` на правильную букву диска, например `D:\rearm.cmd`.

:::
