# Что такое лицензия Office?

Лицензии Office обычно делятся на две категории: розничные (retail) и корпоративные (volume). У разных лицензий разные способы активации и разные сроки действия.

Microsoft также внедряет лицензии vNext для подписок Microsoft 365.

## Розничная лицензия (Retail)

Розничные лицензии можно активировать только с помощью действительного ключа продукта.

Большинство розничных лицензий привязаны к учётной записи Microsoft. Вы можете войти в учётную запись Microsoft в приложении Office, чтобы активировать его. Поэтому розничные лицензии обычно не активируют через Office Tool Plus.

## Корпоративная лицензия (Volume)

Корпоративные лицензии можно активировать с помощью MAK или через KMS.

- Multiple Activation Key (MAK): можно использовать несколько раз в пределах установленного лимита. После активации она становится постоянной.
- KMS-активация — это активация с помощью Key Management Service. Обычно активация действительна 180 дней, если KMS не задаёт другую политику.

::: warning Предупреждение

Лицензии Office LTSC 2021 SPLA не поддерживают KMS-активацию, поддерживается только активация через MAK.

:::

## Лицензия vNext

Лицензии vNext предназначены исключительно для подписок Microsoft 365. Эти лицензии генерируются серверами Microsoft и выдаются приложениям Office. Они защищены цифровыми подписями. Лицензии vNext содержат информацию об учётной записи Microsoft и определяют доступность приложений Office.

Обычно лицензии vNext имеют трёхмесячный срок авторизации, поэтому для непрерывного использования приложений Microsoft 365 требуется подключение к Интернету. У лицензий vNext также есть ограничения по количеству устройств. Версии Microsoft 365 Apps for Personal и Family позволяют использовать 5 устройств, а Microsoft 365 Apps for Enterprise — 10 устройств.
