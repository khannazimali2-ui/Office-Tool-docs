# Активация по телефону {#phone-activation}

## Требования {#prerequisites}

- Ключ продукта Office, который можно использовать для телефонной активации.

## Шаги {#steps}

- Введите ключ продукта Office в разделе управления ключами и нажмите **Установить ключ**.
- После установки ключа нажмите **Обновить** в списке лицензий. Разверните лицензию, которую хотите активировать, и нажмите **Копировать Installation ID**.
- Используйте *Installation ID*, чтобы получить *Confirmation ID* у Microsoft.
- Нажмите **Установить Confirmation ID** в подменю **Установить ключ**, введите *Confirmation ID*, нажмите OK и дождитесь завершения активации продукта.

::: tip Подсказка

Если во время активации возникла проблема, вы можете нажать на синий код ошибки, отображаемый Office Tool Plus, чтобы перейти к возможным решениям.

:::

## Дополнительная информация {#more-info}

Не все ключи продуктов Office поддерживают телефонную активацию, а некоторые ключи блокируются сервером активации. Лицензии, активированные по телефону, являются постоянными, но их нельзя перенести.
