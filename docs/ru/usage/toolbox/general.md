# Общие инструменты

## Запрос версии Office

Вы можете получить информацию о версии канала обновлений Office от Microsoft, включая название канала, ветку, номер версии и время создания.

![Запрос версии Office](/images/en-us/toolbox/query-office-update-channel.webp)

Чтобы отображать внутренние каналы, включите [Показывать внутренние продукты и каналы](/ru/usage/settings.md#показывать-внутренние-продукты-и-каналы).

## Запрос описания кода ошибки

Коды ошибок обычно начинаются с 0x (шестнадцатеричные) или могут быть обычным числом, например 2 (десятичное).

При запросе Office Tool Plus отобразит описание кода ошибки. Иногда может появиться диалоговое окно активации Windows. Нажмите `Show details`, чтобы просмотреть описание кода ошибки.

## Проверка доступности хоста KMS

По умолчанию Office Tool Plus использует TCP-соединение для проверки, можно ли подключиться к хосту KMS.

Введите адрес хоста KMS, затем нажмите кнопку **Проверить**.

::: info Примечание

Замените `kms.example.com` на адрес вашего хоста KMS.

:::
