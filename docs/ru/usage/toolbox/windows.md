# Инструменты Windows

Инструменты Windows находятся на странице `Toolbox` → раздел `Windows tools`.

## Менеджер переменных среды

Менеджер переменных среды предназначен для просмотра или исправления отсутствующих или неверных переменных. Он не поддерживает редактирование или удаление переменных.

Если одна или несколько переменных отсутствуют или неверны, вы получите уведомление об ошибке. Просто нажмите кнопку «Сбросить», чтобы исправить их.

## Сброс службы Software Protection

Будет удалена некоторая информация о конфигурации, связанная с Software Protection в реестре, например адрес хоста KMS и политика продления.

После завершения сброса нужно будет заново настроить хост KMS и активировать Office.

::: details Применимые ситуации

При активации Office возникает следующая ошибка:

- 0x8007000D: Данные недопустимы.
- 0x8007007B: Синтаксис имени файла, имени каталога или метки тома неверен.

:::

## Перестроение токена активации Windows

Будут удалены файлы `data.dat`, `tokens.dat` и `cache.dat`, хранящиеся в папке `%SystemRoot%\System32\spp\store\2.0`.

Windows попытается перестроить эти токены. Статус активации Windows может быть потерян (активация по цифровой лицензии не теряется), а для Office потребуется переустановить лицензии.

Подождите несколько минут, пока Windows перестраивает токен активации, прежде чем выполнять другие операции активации.

::: warning Предупреждение

**Не используйте эту функцию, если у вас нет чёткой необходимости в ней.**

:::

::: details Применимые ситуации

При активации Office возникает следующая ошибка:

- 0xC004E015: Служба лицензирования программного обеспечения сообщила, что потребление лицензии не удалось.
- 0x8004E108: Служба лицензирования программного обеспечения сообщила, что токен в хранилище токенов содержит недопустимый хеш.

:::

## Восстановление компонентов WMI

Все компоненты WMI будут перерегистрированы.

::: warning Предупреждение

**Не используйте эту функцию, если у вас нет чёткой необходимости в ней.**

:::

::: details Применимые ситуации

При установке лицензий Office возникает следующая ошибка:

- Invalid Class.
- 0x80070057: Параметр задан неверно.

:::
