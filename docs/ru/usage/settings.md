# Настройки приложения

Здесь можно настроить язык, тему, фон, параметры скачивания или развёртывания.

Если язык системы не удалось сопоставить, по умолчанию используется English (United States).

::: tip Подсказка

Чтобы сохранить изменения, включите `Сохранить настройки`, иначе все настройки будут потеряны после перезапуска Office Tool Plus.

:::

## Внешний вид и поведение

### Тема

Вы можете вручную выбрать предпочитаемую тему. После включения автоматической тёмной темы Office Tool Plus будет автоматически переключаться между светлой и тёмной темой в соответствии с настройками системы.

### Фон

По умолчанию Office Tool Plus автоматически выбирает фон в зависимости от окружения. На Windows 11 по умолчанию используется эффект Mica, на других системах — обои Bing. Если обнаружена удалённая сессия, фон отключается. Вы можете настроить другие фоны по своему вкусу или использовать локальные изображения в качестве фона (поддерживаются PNG, JPG и BMP).

Если вы хотите установить веб-изображение в качестве фона, используйте команду [/setimage](/ru/usage/command/application.md#команды-в-приложении).

::: warning Внимание

Эффект Mica доступен только на Windows 11. При использовании эффектов Acrylic, Blur или Mica заголовок окна автоматически меняется на стиль Windows 11.

При использовании эффекта Acrylic на Windows 10 может быть задержка при перетаскивании окон.

:::

## Дополнительно

### Аппаратное ускорение

Использование аппаратного ускорения обеспечивает лучшую производительность. Отключение аппаратного ускорения может снизить производительность приложения, поэтому мы не рекомендуем его отключать.

Однако если возникают проблемы, например пустое окно или переполнение памяти при загрузке изображений, их можно избежать, отключив аппаратное ускорение.

Временно отключить аппаратное ускорение можно через [командную строку](/ru/usage/command/application.md#команды).

## Развёртывание

### Формат отображения языков Office

По умолчанию Office Tool Plus отображает языки Office в нативном названии.

- Native: отображает локальное название языков, например *Deutsch* для *German*.
- English: все названия языков отображаются на английском.
- Localized: все названия языков отображаются на языке вашей ОС.

Нативное, английское и локализованное названия предоставляются Windows. На разных версиях Windows результаты могут отличаться.

### Показывать внутренние продукты и каналы

По умолчанию Office Tool Plus не отображает непубличные продукты и каналы обновлений, например продукты вроде `ProPlusVolume` или `MondoVolume`, или каналы обновлений вроде `Dofgood::DevMain`.

Внутренние продукты и каналы обновлений не поддерживаются Office Deployment Tool, поэтому их нельзя использовать напрямую. Однако при необходимости вы можете включить этот переключатель, и Office Tool Plus отобразит эти внутренние продукты и каналы обновлений.

::: danger Предупреждение

Если вы не знаете о внутренних продуктах и каналах обновлений, **НЕ ИСПОЛЬЗУЙТЕ** их.

:::

## Скачивание

### Проверять файлы

После включения Office Tool Plus будет проверять файлы после скачивания установочных файлов Office. Проверка может обнаружить несоответствие версий, повреждение файлов и другие проблемы.

Если продолжить развёртывание Office при повреждённых файлах, процесс установки может зависнуть. Мы настоятельно рекомендуем проверять установочные файлы Office перед развёртыванием.

::: warning Внимание

Проверка установочных файлов Office не работает при онлайн-установке, доступна только в режиме **Скачивание** или когда включено **Скачать сначала, затем развернуть**.

:::

### Подключение через HTTPS

По умолчанию Office Tool Plus использует HTTP-запросы для скачивания установочных файлов Office.

Если скорость скачивания низкая или возникают неожиданные ошибки при скачивании файлов, включите этот параметр и повторите скачивание.

### Движок

Различия между движками:

| Движок                 | Прогресс | Прокси | Пауза и продолжение | Отмена |
| :--------------------- | :------- | :---- | :--------------- | :----------- |
| bezzad.Downloader      | ✓        | ✓     | ✓                | ✓            |
| Office Tool Plus       | ✓        | ✓     | ×                | ✓            |
| Office Deployment Tool | ×        | ×     | ×                | ×            |

Движок по умолчанию — *bezzad.Downloader*.

::: warning Предупреждение

При использовании *bezzad.Downloader* в качестве движка скачивания не рекомендуется устанавливать слишком большое количество **chunks**, если файлы скачиваются на жёсткий диск (HDD): слишком много одновременных **chunks** снизит скорость записи.

:::

### Версия Windows

По умолчанию Office Tool Plus автоматически определяет версию ОС и скачивает соответствующую версию Office. Чтобы скачать установочные файлы Office для других систем, измените соответствующую версию Windows здесь.
