# Команды инструментов

Эти команды можно использовать только в командной строке. Команды не чувствительны к регистру.

``` batch
toolbox params
```

Пример простой команды инструментов:

``` batch
toolbox /rmoffice
```

| Команда | Описание | Использование |
| :--     | :--     | :--       |
| /rmoffice         | Принудительно удалить компоненты Office и связанные записи реестра.  | `/rmoffice`  |
| /rstsppsvc        | Сбросить конфигурацию службы Software Protection. | `/rstsppsvc` |
