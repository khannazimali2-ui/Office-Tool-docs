# Горячие клавиши

- <kbd>F1</kbd>: Показать справку.
- <kbd>Ctrl</kbd> + <kbd>1</kbd>: Перейти на главную страницу.
- <kbd>Ctrl</kbd> + <kbd>2</kbd>: Перейти на страницу развёртывания.
- <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>2</kbd>: Перейти на страницу развёртывания — Расширенные.
- <kbd>Ctrl</kbd> + <kbd>3</kbd>: Перейти на страницу активации.
- <kbd>Ctrl</kbd> + <kbd>4</kbd>: Перейти на страницу инструментов.
- <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>4</kbd>: Перейти на страницу инструментов — Запрос версии Office.
- <kbd>Ctrl</kbd> + <kbd>5</kbd>: Перейти на страницу конвертации документов.
- <kbd>Ctrl</kbd> + <kbd>6</kbd>: Перейти на страницу проверки хеша.
- <kbd>Ctrl</kbd> + <kbd>7</kbd>: Перейти на страницу настроек.
- <kbd>Ctrl</kbd> + <kbd>8</kbd>: Перейти на страницу «О программе».
- <kbd>Alt</kbd> + <kbd>←</kbd>: Вернуться на предыдущую страницу.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>: Открыть командную строку.

## Страница развёртывания

- <kbd>F5</kbd> или <kbd>Ctrl</kbd> + <kbd>R</kbd>: Перезагрузить информацию об Office и сбросить конфигурацию.
- <kbd>Ctrl</kbd> + <kbd>I</kbd>: Импортировать конфигурацию из интернета.
- <kbd>Ctrl</kbd> + <kbd>O</kbd>: Импортировать конфигурацию из локального файла.
- <kbd>Ctrl</kbd> + <kbd>S</kbd>: Сохранить конфигурацию локально.
- <kbd>Ctrl</kbd> + <kbd>E</kbd>: Просмотреть XML-код.

## Страница активации

- <kbd>Ctrl</kbd> + <kbd>D</kbd>: Обновить список лицензий Office.
- <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd>: Обновить список лицензий Office и загрузить все лицензии.
- <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>P</kbd>: Установить лицензии Office.
