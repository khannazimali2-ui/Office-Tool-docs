# Конфигурация по умолчанию

Если в Office ISO есть файл конфигурации по умолчанию, после запуска Office Tool Plus загрузит конфигурацию из `ConfigForISO.xml`. Затем Office Tool Plus автоматически перейдёт на страницу развёртывания и спросит пользователя, нужно ли выполнять развёртывание. Пользователь может выбрать «Да», чтобы начать установку сразу, или «Нет», чтобы изменить конфигурацию и запустить развёртывание позже.

В этом режиме Office Tool Plus сначала ищет установочный файл, указанный в XML-конфигурации. Если он не найден, Office Tool Plus автоматически ищет установочные файлы Office в корневой папке Office Tool Plus (папка Office Tool).

---

Перейдите на страницу развёртывания и измените **Режим развёртывания** на **Создание ISO-файла**.

Выполните следующие шаги:

- Добавьте продукты. Если нужно установить только языковой пакет, продукты можно пропустить.
- Добавьте языки. Если настроить неправильно, установка может завершиться ошибкой или потребовать подключения к Интернету.
- Выберите нужную архитектуру.
- Выберите подходящий канал обновлений.
- Включите **Скачать сначала, затем развернуть**. Без установочных файлов операция не может продолжаться.

Другие расширенные настройки можно менять по необходимости. После выполнения указанных шагов можно нажать «Начать развёртывание».

**После создания Office ISO файл `ConfigForISO.xml` должен автоматически оказаться внутри ISO.**

::: tip Подсказка

Если нужно создать Office ISO, содержащий и 32-, и 64-разрядные версии, измените архитектуру на 64-bit (или 32-bit) **во время скачивания Office**, а затем снова нажмите «Начать развёртывание».

После монтирования Office ISO в контекстном меню CD-ROM должен появиться пункт «Install Now», либо можно запустить Office Tool Plus обычным способом и подтвердить установку.

:::
